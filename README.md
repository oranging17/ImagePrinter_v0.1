# ImagePrinter

Custom Windows Forms application for printing images with structured Korean labels.

## Features
- Image printing with file name, shooting date, device info
- EXIF DateTimeOriginal priority for shooting date
- Justified text alignment for Korean labels

## Note
Source code repository. Official validation documents are managed separately (GAMP 5 Category 5).

## Structure
- `ImagePrinter/Form1.cs` : Main form and print logic
